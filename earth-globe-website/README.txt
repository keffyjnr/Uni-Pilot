EARTH / 01 — video background landing page

HOW TO RUN
1. Extract the ZIP folder.
2. Keep index.html and the assets folder together.
3. Double-click index.html to open it in a modern browser.

The background video is stored at assets/earth-background.mp4.
For a public website, upload the complete folder contents to your hosting provider (for example GitHub Pages, Netlify, or Vercel static hosting).
